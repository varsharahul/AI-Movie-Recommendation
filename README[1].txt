Flowchart submission files

- index.html: a simple webpage displaying the flowchart
- flowchart.svg: scalable flowchart image

To publish as a public link with GitHub Pages:
1. Create a new public GitHub repository (for example, flowchart-submission).
2. Upload index.html and flowchart.svg to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. The public link will look like:
   https://YOUR-GITHUB-USERNAME.github.io/flowchart-submission/

Replace YOUR-GITHUB-USERNAME and flowchart-submission with your actual values.
